# #15：景点详情展开后拖动地图，气泡连续闪烁

本分支基于 `main@c993f38`，只处理 #15 的高德标记更新。

## 原因与修复

一次拖动会触发两条更新路径：`moveend` 立即重排气泡，250ms 防抖后的视口请求返回时再更新活动。原实现反复调用 `setMap`，并在每次响应后移除全部活动标记、重建 DOM，重复播放入场动画。

现在按稳定的地点分组 ID 保留 Marker 和气泡 DOM，只在可见性、布局或数据确实变化时更新。标题、价格、图片和详情点击使用最新数据；离开视口或因避让需要隐藏的点仍可正常移除和重新显示。景点名称标记也避免重复挂载。没有改动底图、后端接口或详情卡动画。

- `node --test test/frontend-amap.test.ts test/frontend-activities.test.ts`：23 项通过。新增回归覆盖拖动结束加视口响应时复用标记、只更新变化的偏移、移除消失的点、最新数据点击回调，以及原位更新价格与封面。

- 定位到永兴坊，点击气泡展开详情，再连续拖动三次。观察地图 DOM：修复前第一次拖动有两轮移除（间隔约 341ms），6 个可见气泡全部重建；修复后永兴坊气泡三次均保留同一个节点，移除次数为 0。其他点因避让而改变显隐；没有全量重建。
- 关闭详情后再次拖动：10 个可见气泡全部保留，移除次数为 0。
- 每次拖动均确认中心坐标发生变化；稳定布局后检测气泡与左右卡片及其他气泡不重叠。随后缩放到 15 级，并再次点击气泡，详情正常打开。
- 浏览器未发生未捕获的 JS 异常。

测试边界：此环境中高德矢量底图请求返回 403（SDK 报 `FlyDataAuthTask error: param version not valid`），因此录屏背景缺少道路；原生 SDK 的标记投影、拖动、缩放和详情交互已运行并完成验证。本 PR 没有修改高德鉴权或底图加载，也不以该录屏证明底图加载正常。Leaflet 回退渲染不在本次修复范围内。

## 人工复测

按 [高德接入说明](../../integrations/amap.md) 配置本机环境，运行 `npm run dev:web`。打开地图，搜索永兴坊，点击其活动气泡展开详情。连续小幅拖动并等待视口请求返回，观察同一气泡是否闪烁两次；关闭详情后重复，再缩放及点击其他气泡，检查避让与详情是否正常。
