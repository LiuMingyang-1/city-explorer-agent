## 运行中断与修复

1. DeepSeek曾返回HTTP402/INSUFFICIENT_BALANCE，任务在140个目标完成后中断。用户充值后，通过官方只读余额接口确认可用，继续未完成批次，已完成140目标没有重新采集。补充了同客户端鉴权/余额失败后不再重复HTTP及后续文档停止的保护。
2. 原SYNTHETIC_CONTENT粗规则只要看到“模拟”就拦截，误伤航空体验馆、防震科普馆等。改为明确的模拟数据/虚构活动标记；5个受影响目标共9份资料用保存的模型和高德结果离线重放，不重新付费搜索。
3. 浐灞滋水公园参考网址超过400字符，误套用了短备注限制。网址改为8192字符上限，主体/地图/费用检查保持；201—205目标的10份缓存资料重放通过，新增API请求0次，进度推进后继续余下清单。
4. 其他模型结构失败按有限重试处理；没有无限翻页或换词凑数量。历史失败记录保留在journal和原运行目录，不用后来成功覆盖原失败证据。
