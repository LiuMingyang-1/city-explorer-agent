## 修复及验证

初次仅网页 3 条通过。发现地点匹配把高德返回的“西安荟聚B01区”“西安荟聚B11区”也当成输入楼层说明清理，导致与“西安荟聚”产生假重名。

现在仅清理来源输入的楼层说明，保留高德 POI 名称；正式名称精确匹配优先于别名匹配。真正存在多个同名候选时仍不任意选择。新增 2 项针对性测试，完整 Node 测试 515 项全部通过；针对性测试和 TypeScript 检查也通过。

通过结果按 27 个业务字段导出，并写入隔离样本库，逐字段读回校验和 SQLite 完整性检查通过。物理表仍含临时兼容的 start_at/end_at 共 29 列。坐标保持高德 GCJ-02，guide_url 为原来源链接。正式 data/events.db 的哈希前后相同。
