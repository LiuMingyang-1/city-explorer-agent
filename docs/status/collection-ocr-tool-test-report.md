初次完整处理约209.718秒；小红书OCR和多轮工具调用是主要新增耗时。以上是串行小样本实测，不应外推为稳定的每篇延迟。包含修复复测的真实调用共49次模型HTTP请求、41次高德HTTP请求；搜索5次单独计数。模型HTTP请求数量多于文档数量，因为工具调用需要多轮交互，且初次第4篇的失败曾触发一次重试。

每篇最多OCR前10张，第二篇有17张，7张未识别，已在该文档指标中记录。未识别图片不能当成没有活动内容；本轮未进行全图覆盖的验收。

本次实际OCR共36张图片，累计约129.158秒，已处理图片未报告识别执行错误。这不代表OCR文字逐字准确；错误执行与识别文字准确率是两件事。
