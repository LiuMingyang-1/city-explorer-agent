# #33 高德标识与版权布局

2026-11-15，从 `main@535826d` 创建独立分支。

采用集中 CSS 对 JS API 2.0 原有 `.amap-logo` / `.amap-copyright` 定位，右对齐、分行放在地图右下角；不是 Android/iOS 的位置 API，也不宣称是 JS API 官方位置选项。保留原 DOM、图片尺寸、版权文字及 SDK 提供的链接，不复制标识、不改写文本或 URL。版权文字使用浅底深字确保清晰。

版权 border-box 高度经 ResizeObserver 传入 CSS 变量；缩放控件与展开面板避让这一实际高度。手机为原标识留出底部空间并相应缩短卡片，地图仍全屏；面板覆盖地图时暂不展示被覆盖的缩放控件。销毁地图会释放观察器与布局标记，重建后重新绑定。

实施前核对了[开放平台服务协议](https://lbs.amap.com/pages/terms/)中 7.4–7.8 的标志与归属要求，以及 [JS API 2.0 公开文档](https://a.amap.com/jsapi/static/doc/index.html)。前者要求完整保留归属内容；本实现仅调整原元素布局，未使用或套用原生 SDK 的 logo 位置方法。

验证：

- `npm run check`：类型检查、890 项测试通过；`npm run check:frontend` 通过。
- 高德专项 13 项通过，新增版权实际高度变化、border-box 观察及销毁后晚到回调不会写回的覆盖。
- 真实高德 JS SDK 2.0：1440×900、823×880、390×844、320×740、1440×600，分别检查欢迎、活动详情与记忆面板展开，再刷新和重建地图；标识与版权均位于右下角，没有重叠、裁切或副本。
- 额外放大版权区域高度，标识与控件自动上移避让；原文字、节点与图片未被替换。
- 当前测试服务返回的 SDK logo 节点没有 href，保留其原行为，不人为补造链接。条件样式保证 SDK 提供非空 href 时仍可点击；不以本次环境宣称真实外站导航成功。
- 测试环境高德矢量底图仍返回 403，因此这里只验证实际 SDK 归属节点和布局，不证明底图服务可用。浏览器无未捕获异常。
