# #35 欢迎区天气与位置对齐

2026-11-15，从 `main@535826d` 创建独立分支。

欢迎区使用统一两行网格：第一行是天气图标、温度、单位及描述，第二行是位置搜索与圆形定位按钮。搜索框与定位按钮同为 36px 高，内部图标与文字居中。窄屏使用紧凑图标和温度比例，长地名保留完整输入值并在可视区域省略显示，长天气描述不挤压温度。为两行天气保留输入框间距；样式只作用于欢迎状态。

验证：

- `npm run check`：类型检查、889 项测试通过；`npm run check:frontend` 通过。
- Chromium 检查 1440×900、823×880、390×844、320×740。
- 每种宽度检查 -12.5、0、35，以及长地名和长天气描述；无横向溢出、控件重叠，天气区与输入框不相交。位置框和定位按钮的垂直中心误差小于 1px。
- 实际点击搜索按钮走既有地址查询与地图定位流程；模拟浏览器定位回调后地点及天气刷新正常。地址、天气和定位使用固定测试响应，未调用真实定位服务。
- 控件 DOM、事件处理和后端协议保持原有实现。浏览器无未捕获异常。
