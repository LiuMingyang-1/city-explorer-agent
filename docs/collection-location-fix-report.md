## 修复内容

- 支持带秒、毫秒、UTC及显式时区的活动时刻，统一转换为北京时间YYYY-MM-DDTHH:mm。日期本身或非法日期不会被补造为午夜。
- 模型输出和结构化输入都在时间窗口校验前标准化。未知结束时间仍保留NULL，不估造散场时间。
- 地图搜索拆分1F舞台、东区通道、中文楼层和1号门前等内部位置，保留原venue_name供展示，坐标定位场馆主体。
- 初次搜索没有匹配时，最多再去掉重复城市名、缩短为品牌名；匹配时仍保留分店区别。支持高德明确提供的别名和有限字形/标点差异，不把不同分店视为同一店。
- 5分钟内共享同一关键词的候选查询，多个楼层/活动不反复发相同请求；失败不持久缓存，后续夜间批次会重新查询。
- 增加脱敏诊断回调，记录查询词、候选名称地址和匹配阶段，不记录API Key；品牌存在但目标分店未确认时单独返回BRANCH_NOT_CONFIRMED。
