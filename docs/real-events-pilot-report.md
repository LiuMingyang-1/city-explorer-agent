# 西安真实活动：首批搜索与字段提取实测

日期：2026-11-12（Asia/Shanghai）。本批只验证小样本，不扩大正式采集，不写运行数据库。

结论：两家搜索 API 可用，DeepSeek 返回的正文可以支持部分字段提取；当前资料补全、候选筛选及证据生成尚不能可靠产生完整 events。数据质量关卡未通过，不能因为程序测试成功就扩大规模或发布数据库。

## 1. 本次实际调用量

- 查询类别：展览、演出、市集、读书会、工作坊，均限定西安；DeepSeek 查询附 2026 年 11 月。
- Qovia 5 次搜索，每次第一页 20 条；DeepSeek 5 次搜索，每次最多 20 条并请求正文。
- 总计 200 次命中，按原始链接去重后 195 份资料：Qovia 95、DeepSeek 100。这不是 195 个真实可参加活动，尚未做跨平台内容级活动归并。
- 首轮选择 5 份资料调用 deepseek-flash。另对一次截断失败及一份已有且含开放规则的资料进行两次复测，共 7 次模型请求、6 份不同资料。复测未增加搜索，也未扩展资料池。
- 首轮 5 次：2 份返回空活动数组、2 份提取到候选、1 份被输出额度截断。复测两份均返回 JSON，共得到 4 个不同资料中的候选活动；均未批准入库。
- 搜索与模型原始响应、正文、提取结果保存在 `.local-data/xian/pilot-20261112-01/`，该目录被 Git 忽略。没有提交第三方整批原文、密钥或用户账号数据。

## 3. 返回资料的实际质量

### Qovia

本批返回的 text 多是片段，不能视为全文。发现广告、仅“转发微博”的空洞内容、明年活动、事后回顾，以及“辽源市西安区”等同名地域误命中。也有高校展览、读书会及市集线索，但日期、具体地点和开放安排常不完整。

首轮按年份、月份、长度选择候选的简单评分选中了无关会议资料，说明不能用“内容较长、含年份”代替旅游相关性判断。下一步须增加内容相关性和行政归属筛选，再取平台详情或追查主办方原文。不能把更多相同片段送给模型当作扩大有效活动覆盖。

### DeepSeek

本批返回部分可直接使用的网页正文，包括展览预告、活动详情与博览会公告。也混有已结束活动、医疗职业培训、广告、售票页空壳和与目标参加日期不匹配的内容。

例如“三秦四季·绘览河山”预告正文明确提供展期、场馆与地址，但没有每日开放时间和坐标；这几项缺失不是换个模型就能可靠补出。

## 4. 能提取哪些 events 字段

实际提取示例（候选，不是可入库记录）：

```json
{
  "title": "三秦四季·绘览河山——主题美术作品展",
  "category": "展览",
  "venue_name": "陕西省美术博物馆",
  "address": "西安市长安北路14号",
  "start_at": null,
  "end_at": null,
  "latitude": null,
  "longitude": null,
  "suggested_duration_minutes": null,
  "budget_min": null,
  "budget_max": null
}
```

原文有 2026-11-11 至 11-29 的展期，但不应直接填成连续 18 天的开放窗口。需要补场馆开放时间、闭馆日、坐标，再由程序展开每日时段。模型能够抽出名称/类别/场馆/地址/费用说明，仍不能代替信息补全。

另一份共读营资料同时包含全年报名期、线上开营、每周线上读书和每月线下聚会；仅有页面总地址，具体线下地点报名后通知。本批不予入库，避免将全年报名期或线上活动当成线下参加窗口。

另一份沙龙资料有“每天 14:00–21:00”的规则，模型保留在 schedule_note，尚未形成具体日期的 start_at/end_at。后续应采用结构化开放规则并由代码展开，而不是让模型自行生成整批日期。

## 5. 发现的提取问题与修复

1. DeepSeek 当前文档说明思考模式默认开启。首轮有一次 35.168 秒请求全部 6000 completion tokens 用于推理，finish_reason=length，最终 content 为空。已显式设置 thinking.type=disabled；保留原失败记录，没有伪装为有效结果。[官方说明](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)
2. 非思考模式两份复测分别耗时 3.213 秒、1.975 秒，均输出可解析 JSON。样本只有两份，不能据此保证所有正文都在该范围完成。
3. 模型会在证据中拼接原文、增加省略号，或用一个 budget 引用代替两个价格字段的引用。当前逐字证据检查已拒绝这些不合格引用，不能只检查 JSON 合法。
4. 本地时间校验补上“只提取到一个边界也检查目标日期范围”，避免缺 end_at 时漏报过去 start_at。
5. 保持坐标缺失为 null，不让模型凭记忆填写，也没有拿粗范围或城市关键词代替场馆核验。

## 8. 本地复现

```powershell
node scripts/collect-pilot.ts --date=2026-11-12 --run=pilot-20261112-01 --smoke --search-only
node scripts/collect-pilot.ts --date=2026-11-12 --run=pilot-20261112-01
```

相同 run 优先复用已存在的搜索与提取文件，不重复收费；新 run 会发新请求。每个初次运行最多 10 次搜索、5 次提取，原始资料只存在本地忽略目录。

`--recheck` 必须传入一至两个来自同批缓存的 `--extract-url`，另存 recheck 文件，不覆盖首轮报告；本次复测共两次，无新增搜索。配置更改不会自动使旧缓存失效，后续正式工具需引入模型/提示词版本缓存键。
