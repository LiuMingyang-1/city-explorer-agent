# Demo采集设计收尾验收

日期：2026-11-13。分支：feat/xian-nightly-events。

本轮对5篇未在前面三批小红书样本出现的新帖子，以及5份新网页来源执行真实测试。当前Demo的表结构、OCR与模型高德工具流程、时间备注及坐标去重设计可以收尾。后续优先积累数据、修正提取质量，不继续扩展表结构。

该结论只覆盖本轮验证范围。此前“西交创新港”测试出现的在建项目误收、主题偏离和教育机构过宽归类，仍属于已知数据质量修正项，本轮未将其宣称为已修复；也不据此宣称全平台内容准确率已完成验收。

未保留两条：

1. 曲江池历史博物馆：模型没有确认到对应高德地点，ID和坐标为空，未使用推测坐标。此结论不表示该场馆不存在。
2. “秋日拾趣，好物相逢”野趣跳蚤集：报道明确称活动已“欢乐收官”，模型判断为past，程序按已结束活动拦截。

时间状态为complete 1条、partial 6条、unknown 6条、conflicting 2条。时间缺失或矛盾转入备注，不因其格式或完整度直接丢掉主体。仅程序保留不等于可以直接排入具体钟点。

## 验证

- TypeScript检查及533项Node回归测试通过。
- 24张图片全部执行本地OCR，无执行错误；OCR累计约57.361秒，不代表文字识别逐字准确。
- 通过项逐字段SQLite读回、31列结构及integrity_check通过。
- 多来源数据实际写入同一个隔离发布库，得到15条记录，旁路元数据正常。
- 7条景点最小相距约686.11米，没有10米内应合并的重复点；多个同地点活动没有被误合并。近坐标及跨批次重复由新增的7项自动测试和前一轮创新港真实样本回放覆盖。
- 发布库按2026-11-14检索返回13条候选。曲江池可解析开放窗口，大明宫时间冲突仍返回unknown，已结束市集不在库中。
- 32次模型HTTP请求中有1次网络错误，已在现有预算内自动重试成功。26次高德HTTP请求均返回10000成功码，没有业务限流。
- 正式data/events.db前后哈希相同，未写入；密钥、账号状态和原始采集资料均未提交。
