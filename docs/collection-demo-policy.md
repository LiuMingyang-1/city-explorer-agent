# Demo活动采集校验规则

日期：2026-11-12。此文覆盖上一轮严格字段引用和地址交叉核对规则；原events表不变。

## 删除或放宽的限制

| 原限制 | 当前规则 |
| --- | --- |
| 引用必须是正文片段 | 删除；提取说明可概括、可不填，不检查正文包含关系 |
| 标题、简介、场馆名必须被引用逐字包含 | 删除；允许模型忠实概括，场馆身份由地图确认 |
| 每个字段都必须提供引用 | 删除；最终发布校验也不再要求逐字段引用。保留原始来源URL和可选说明 |
| 简介不逐字匹配就替换成正文片段 | 删除；保留模型生成的简介 |
| 日期必须出现在引用里、票价必须带固定措辞、时长必须原文出现 | 删除机械字符检查，保留格式、日期合法性和数值关系校验 |
| 估计时长一律不接受 | 可接受，在provenance标记estimated；没有依据的费用仍提示模型填null，不把未知当免费 |
| 无结束日期一律拒绝 | 近期首次发布或无发布时间但近期抓取的候选可暂存；超过7天且仍不能确认有效期则拒绝，已收录记录仍受时效元数据限制 |
| unknown状态一律拒绝 | 可以暂存并保留unknown，不能伪装成active；明确past/cancelled仍拒绝 |
| 正文包含回顾关键词就全篇拒绝 | 删除全篇词语否决，使用活动级语义状态，合集中的一个回顾不直接否决其他活动 |
| 正文被标记摘要/可能截断就拒绝 | 不单独否决，依赖提取结果与其他必要条件 |
| 帖子地址必须匹配高德街道/门牌/区县 | 唯一场馆或分馆匹配后以高德为准，原地址留在原始资料；多个同名候选时原地址仅用于辅助区分 |

可选说明的字符串形式自动转为summary对象，避免为非业务字段再次请求模型。旧说明与原始资料hash仍保留关联，以防资料被改动；该完整性检查不等于逐字引用要求。

## 保留的条件

- 名称、简介、固定分类、场馆等必填项；数据类型和金额/分钟单位正确。
- 来源URL、原始资料hash及凭据保密检查。
- 明确取消、回顾、结束状态不收录，结束日期或时刻已过不收录。
- 日期存在、先后顺序正确、具体时间窗口有效，费用上下界和时长关系合理。
- 明确的未解决事实冲突；14天批次业务范围和已有新鲜度限制。
- 最终地点属于西安，坐标有效；多个场馆/分馆无法区分时拒绝，不能随便取搜索第一条。
- 发布前仍检查位置绑定、坐标转换、ID一致性、重复记录及数据库原子切换。

服务超时、Key/配额错误属于运行失败，不等于活动不真实。不能为了消除格式错误编造事实。
