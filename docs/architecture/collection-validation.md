## 流程与责任

| 环节 | 实现 | 实际检查 |
| --- | --- | --- |
| 本地资料入口 | cached-input.ts / mediacrawler.ts | 启用平台、链接、正文存在、正文hash、时间字段等基础格式 |
| 语义提取 | extraction.ts调用deepseek-flash | 拆分活动、类别、标题简介、日期、场馆分店、状态、冲突；输入包括当前时间、发布时间和编辑时间 |
| 输出结构 | Ajv JSON Schema | JSON、必填、字段类型、固定类别、正时长/非负整数金额、未知值可空；模型不能提供坐标或发布许可 |
| 自动标准化 | completeFacts / time-normalization.ts | 秒/时区转北京时间分钟，有条件补年，未知状态结合日期及取消/回顾语义处理；不补造缺失钟点 |
| 本地事实规则 | checkFacts | 日期、时段、过期、数值范围、冲突列表、采集窗口、新鲜度；不再逐字校验引用 |
| 定位 | createGeocoder | 拆分楼层入口、分店查询回退、候选及别名匹配、西安行政区、有效坐标；同场馆采用高德地址，不能拿其他分店替代 |
| 最终组装 | prepareCollection | 重查必要事实、坐标与原查询绑定、坐标转换一致、稳定ID；guide_url=document.url |
| 最终数据检查 | validateDataset | 18列形状、日期范围、坐标、来源URL、guide_url与来源记录一致、重复ID、引用资料hash完整性 |
| 实验发布 | releases.ts | 重新复核资料、临时库upsert、SQLite完整性、原子切换；没有默认写正式库 |

## 当前仍在执行的规则

- category固定12类；名称、简介、场馆等不能为空白。时间和建议时长可以为空，费用未知为空，不能将未知当免费。
- status为past/cancelled则拒绝，unknown可暂存；模型返回非空conflicts数组则拒绝。
- 日期真实存在，开始不晚于结束；一个具体窗口不能超过24小时，时长不得超过完整窗口，最低费用不得高于最高费用；固定场次仍执行时长一致性。
- 确认已过期则拒绝；当前批次约14天，不接收超范围记录。这是业务收集范围，不代表资料虚假。
- 抓取超过36小时视为陈旧；无结束日期且无长期开放说明的普通信息，发布/抓取超过7天不继续当作有效候选；已收录数据还有firstSeen及核验时效规则。
- 非空guide_url必须是可接受的公开URL，并与provenance.source_url一致；图片链接等也进行URL检查。
- 没有可信城市匹配和坐标不能作为可发布events；候选预览允许坐标为空，明确标记未通过。

## 并非事实证明的部分

- 语义准确性主要依赖模型：本地没有第二个理解模型重新判断标题、简介或冲突是否合理。
- conflicts仅判非空；目前没有按主办方内容/用户评论做可靠的冲突分级，评论可能导致误判。
- 多日展期展开成每日开放窗口尚未实现；跨日连续窗口会被拒绝，需要拆分后再处理。
- 地图服务失败目前也进入未通过报告，缺少完整的业务错误码记录和自动重试队列；不等于场馆或活动不存在。
- ID与重复检查不是跨来源语义去重，同一活动来自两个不同网页仍可能形成两个候选。
- 未使用逐字引用作为通过前提；保留资料hash检查是为了防止缓存被改动，不要求说明文本出现在正文中。
